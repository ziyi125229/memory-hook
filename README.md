# Memory Hook

个人记忆助手。用自然语言记录物品位置与借出关系，结构化保存，并支持自然语言检索。

当前版本：**V1.6**

## 打开方式

用浏览器直接打开 `memory-plugin-demo.html`。

语音识别建议使用 Chrome / Edge，并通过本地静态服务访问（例如 `python3 -m http.server`）。

## V1.6

- 口语解析：支持「扔 / 塞 / 搁 / 放茶几」等表达
- 不确定性防护：无法确定的实体不进入当前状态，不确定时不胡答
- Query Understanding：区分当前状态与历史，理解「现在 / 刚才 / 最后一次 / 以前」
- 多实体解析：支持「钥匙和钱包」，以及「黑色钥匙 / 银色钥匙」等属性区分
